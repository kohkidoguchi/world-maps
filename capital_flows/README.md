# 世界資金循環ダッシュボード（capital_flows）

政府・企業・家計・金融機関・海外 × 支出・投資・債務を、同じ会計体系（資金循環統計 / 部門別勘定）で結び、
**遅いが正確なマクロ時計**（四半期・年次の正式統計）と**速いが部分的なマーケット時計**（日次・週次の公開データによるNowcast）を
上下二層で重ねて表示する。公開APIのみで動く。

```
IMF SDMX (WEO / BOP / IIP)   OECD SDMX (QSA / 金融勘定 / 公的債務 / QNA)   ECB Data API (QSA / W2W / BPS / GFS / EXR / YC / ILM)
FRB Z.1 (CSV zip)            BIS SDMX (総債務 / USDJPY)                    米財務省 Fiscal Data (日次債務 / TGA / MTS)   財務省 (週次対外対内証券投資)
        │
        ▼  pipeline/  →  共通データモデル  area × sector × counterpart × instrument × stock/flow × period × status × release
        ▼  build.py   →  data/observations.csv（全観測値・約40万行）, data/sources.json（鮮度台帳）, web/data.json（表示用）
        ▼  web/       →  世界地図（G20）・二層Sankey・部門タイル・時系列・Nowcastカード・出所台帳
```

## 使い方

```bat
pip install -r requirements.txt
python build.py            # 全ソース取得 → CSV → web/data.json（初回 約2分、以降はキャッシュで高速）
serve.bat                  # http://localhost:8765 で表示（python -m http.server）
run_daily.bat              # 日次更新用（タスクスケジューラに登録する。コメント参照）
python build.py --json     # 取得済みCSVから data.json だけ再生成（ネットワーク不要）
```

BCGのSSLプロキシ配下では `truststore` がWindows証明書ストアを使う。FRED と IMF DataMapper はこのネットワークから到達不能のため使っていない
（IMFは新SDMX API `api.imf.org`、米国の日次はFRED の代わりに財務省 Fiscal Data を使用）。

## データモデル（data/observations.csv）

| 列 | 意味 |
|---|---|
| src | 取得元（IMF_WEO, OECD_QSA, OECD_FA_FLOW, ECB_QSA, FED_Z1, BIS_TC, UST_DEBT, MOF_WEEKLY …） |
| area | ISO3（EA＝ユーロ圏） |
| sector | HH 家計 / NFC 非金融法人 / FIN 金融機関 / GOV 一般政府 / GOV_C 中央（連邦）政府 / ROW 海外 / TOTAL 国内計 / CB 中央銀行 |
| concept | ESA2010系コード：B9 純貸出／純借入, B8G 粗貯蓄, B6G 可処分所得, P3 消費, P51G 総固定資本形成, D1 雇用者報酬, D4 財産所得, D41 利子, D5 所得税, D61/D62 社会保険料／給付, OTR/OTE 政府収入／支出, FIN 金融取引・残高, DEBT 債務, CA 経常収支, FA 金融収支, GDP |
| entry | A 資産 / L 負債 / N 純 / B バランス項目 / C 受取 / D 支払 |
| instrument | F2 現金・預金, F3 債券, F4 貸出, F5/F51/F52 株式・投信, F6 保険・年金, F7/F8 その他, FD 直接投資, PI 証券投資, OI その他投資, RA 外貨準備 |
| cp_sector | 相手部門（ユーロ圏の whom-to-whom のみ） |
| measure / unit / unit_mult | flow・stock・ratio・price ／ XDC（自国通貨）・USD・PT_GDP ／ 10のべき乗 |
| period / obs_date / freq | 観測期間（2026-Q1, 2026-08, 2026-09-10）／期末日／A Q M W D |
| status / release | actual・preliminary・forecast・nowcast ／ 公表・更新日（提供元が持つ場合） |

残高の変化 ＝ 取引 ＋ 価格・為替変動 ＋ その他変動 のうち、取引（flow）と残高（stock）を別系列で保持する。
評価変動は stock の差分 − flow で導出できる。

## 二層の設計

* **①所得・支出の層**：左＝支払う部門、右＝受け取る部門・投資。家計→企業（消費）、企業→家計（雇用者報酬・財産所得）、家計・企業→政府（税・社会保険料）、政府→家計（社会給付）、政府→企業（政府消費）、各部門→投資、政府→利払い。
  米国はFRB統合マクロ勘定の分類をESAに近似（個人所得＝賃金＋財産所得＋…、「social contributions paid」＝社会給付）し、近似は破線で示す。
* **部門別純貸出／純借入**：家計・企業・政府・金融機関・海外（＝−経常収支）。国内4部門＋海外＝統計上の不突合。
* **②資金調達・運用の層**：左＝金融資産を純取得した部門、中央＝金融商品、右＝負債を純増させた部門。商品ごとの「誰が取得」「誰が発行」は実績。
  「誰から誰へ」の対応は商品を経由した近似（ユーロ圏はECBの whom-to-whom 系列 `ECB_W2W` を保持しており、直接描画に拡張できる）。純減は表に分離。
* **Nowcast**：米＝日次連邦債務・TGA・月次財政収支（MTS）、日＝週次対外・対内証券投資（財務省）・ドル円、欧＝週次ユーロシステム総資産・10年利回り・ユーロドル。
  正式統計の最終四半期末以降の累積変化を「推計」バッジ付きで示す。

## 初期版の範囲と既知の制約

* 世界地図＝G20＋スペイン・オランダ・スイス・シンガポール・香港・アイルランド、部門別詳細＝日本・米国・ユーロ圏、企業＝非金融法人部門の集計値。
* 日本の非金融部門別勘定（OECD QSA, 内閣府SNA由来）は公表ラグが大きい（最新 2025-Q1）。金融勘定（日銀資金循環統計由来）は 2026-Q1。家計の住宅投資はOECD系列に無いため国内計−他部門の残差（推計）。
* 米国の非金融部門別勘定は OECD に無いため FRB Z.1 統合マクロ勘定から直接取得。政府＝連邦＋州・地方（Z.1）。
* ユーロ圏の海外部門は ECB BP6（ユーロ建て）と IMF BOP（ドル建て, G163）の両方を保持。
* 二国間フロー（IMF PIP／DIP＝旧CPIS／CDIS）は構造を確認済みだが未取り込み（世界地図の「矢印」は次段階）。
* 商用の日次ファンドフロー（EPFR等）は使わない。ICI週次・TIC月次は未取り込み。

## 第2版で追加したもの（2026-09-12）

1. **二国間残高の矢印**（IMF PIP＝旧CPIS：保有国→発行国の証券投資残高、総額・債券・株式／IMF DIP＝旧CDIS：投資国→受入国の直接投資残高、投資国申告と受入国申告の両方）。
   地図で矢印の種類と年末を選び、国をクリックするとその国の対外（青）・対内（橙）に絞られる。国カードに主な相手国上位5。
   注意：金融センター（ケイマン、ルクセンブルク等）経由の保有は対象国リスト外のため現れない。相手国申告の非対称もある。
2. **whom-to-whom の直接表示**：金融層の「相手部門別で表示」トグル。ユーロ圏＝ECBの保有部門×発行部門（債券・貸出・投資信託、4四半期フロー；預金・保険年金は定義上金融機関宛てで破線）。
   日本＝日銀「債券の保有部門×発行部門」（`sjds.xlsx`、四半期末残高、債券のみ）。日銀は他商品の whom-to-whom をフラットファイルで公表していない。
3. **対象経済の拡張**：英国・ドイツ・フランス・イタリア・スペイン・オランダ・カナダ・オーストラリア・メキシコ・韓国（OECD 部門別勘定・金融勘定・公的債務）。
   中国・インド・ブラジル等は部門別勘定の公開APIが無いため、地図（WEO・BIS・IMF BOP/IIP・PIP/DIP）と四半期GDPのみ。
   上場企業の集計値（決算・社債発行・自社株買い）は無償の機械可読ソースが無く未実装（候補：各国証券取引所の統計、EDINET/XBRL集計）。
4. **改定履歴**：毎回の取得値を `data/vintages/obs_YYYY-MM-DD.csv.gz` に保存し、前回との差を `data/revisions.csv` に追記。画面末尾に主要項目の改定率上位を表示。

5. **資金の流れマトリクス**（「主要地域×経済主体で、どこからどこへ」）。
   国際：行＝保有地域×保有主体（政府・中銀／銀行／その他金融／企業・家計）、列＝発行地域（オプションで発行側も政府／金融／企業・家計に分割）、
   セル＝クロスボーダー証券保有残高（IMF PIP、総額・債券・株式、2019–2024年末、前年差表示可）。地域＝日本・米国・ユーロ圏主要6か国・英国・中国・金融センター・その他先進・新興国。
   国内：選択経済の保有部門×発行部門の残高。ECB whom-to-whom（債券・貸出・投信）と日銀「債券の保有部門別」は実績（太枠）、
   それ以外は保有側残高を発行側の負債残高シェアで比例配分した推計。金融商品で絞り込み可。

## マトリクス専用ページ（web/matrix.html）

ダッシュボードとは別に、マトリクスだけを見せる軽量ページ。`serve.bat` 後に http://localhost:8765/matrix.html 、
単一ファイル版は `python build_dist.py --matrix` → `dist/matrix.html`（データは `web/matrix_data.json` 1.5MB を内包）。

* **BS（残高）**＝いま誰が誰の資本を持っているか。**CF（フロー）**＝この期間にどこからどこへ流れたか。上部の切替で完全に分ける。
* **国際（地域×主体）**：BS＝IMF PIP の証券保有残高（実績）。CF＝二国間の取引フローは公表統計に無いため、残高の前年差（取引＋評価変動）を推計として表示し、
  左下に IMF 国際収支の実績（地域別・4四半期）を照合用に置く。
* **国内（部門×部門）**：BS＝残高、CF＝4四半期の取引。ECB whom-to-whom と日銀の債券保有部門別は実績（実線の円）、他は比例配分の推計（点線の円）。
* 左＝コード図（地域／部門間の相互関係、色＝出し手）、右＝バブル・マトリクス（面積＝金額、CFは緑＝流入・赤＝引き揚げ、行・列合計バー付き）。
* **世界を一枚で（国内＋国際）**：行・列＝地域×主体（政府／金融／企業・家計）。対角ブロック＝国内の部門×部門（資金循環統計、年末レートでUSD換算、全金融商品）、
  非対角＝地域間の証券保有（IMF PIP）。発行側の部門が申告されていない分は発行地域の証券発行残高シェアで配分（推計）。
  「その他海外」行・列＝資金循環統計の海外部門との残高のうちPIPで相手地域を特定できない残差（貸出・預金・直接投資・外貨準備・金融センター経由）。
  ユーロ圏内の相互保有は国内ブロックに含め、PIPのユーロ圏→ユーロ圏は除外。円の大きさは既定で対数（国内の巨大残高と国際の小さな保有を同じ絵で見るため）。
  USD換算レートは OECD 金融勘定のUSD系列／自国通貨系列の比（ユーロ圏はECB参照レート）。

* **矢印図（既定ビュー）**：横＝地域、縦＝主体（政府／金融／企業／家計）。セルからセルへ金額に応じた太さの矢印（保有・貸し手→発行・借り手）。
  同じ地域の中の矢印＝資金循環統計、地域をまたぐ矢印＝IMF PIP。PIPの「企業・家計」保有は各地域の家計／企業の証券保有シェアで分割、発行側の部門が無い分は証券発行残高シェアで配分（推計）。
  同じ部門内（銀行間など）は矢印にせず枠の太さで表現。上位N本・国内矢印・その他海外への矢印の表示を切替。
  向き：矢印は貸し手・出し手側が太く（●印）、借り手・受け手に向かって細くなり矢先▶で終わるテーパー形状。各セルに「● 貸し手・保有」「▶ 借り手・発行」の金額。
  セルをクリックすると、その主体の矢印だけを表示し、青＝その主体が貸し手、橙＝借り手で塗り分ける。
  CFモードでは矢印ホバー時に「発行国通貨の対ドル変化による為替評価の目安」と「残り＝取引＋価格変動」を分けて表示し、
  下部に「この年の背景（解釈）」（金利・為替・政策・市場価格の整理、2021–2024）と「データで見る背景」（IMF WEO の経常収支・財政収支・成長率・インフレ、為替の年間変化）を付ける。

### 時点の鮮度（マトリクス／矢印図）

* 二国間残高（IMF PIP）は半期系列を使用：年末（-12）と6月末（-06）。2026年9月時点の最新は 2025年6月末（12月末分は例年9月頃に公表）。
* 国内の資金循環統計は四半期で 2026年Q1 まで、国際収支フローは 2026年Q1〜Q2 まで。
* **Nowcast 時点**（例：2026-Q1、推計）：国内ブロック＝実績の四半期残高／4四半期フロー。地域間＝最新PIP残高に、その後の各地域の証券投資フロー
  （IMF国際収支、相手国不問）を二国間シェアで配分して積み上げ（BS）、または直近4四半期のフローを配分（CF）。評価変動は含まない。
  `matrix.js` の `crossCells()`。BS既定はこの最新推計時点、CF既定は最新の実績時点。

## 第4版（2026-09-12 夜）── 三つの尺度を厳密に分ける

* **① 実取引フロー（TX）**：期間中に実際に取引された資金。国内＝資金循環統計の金融取引（4四半期合計）、国際＝IMF国際収支の証券投資フロー（同じ4四半期）を直近PIPの二国間シェアで配分（金額は実績、相手先の内訳は推計）。価格・為替の評価変動を含まない。
* **② 保有残高（POS）**：時点のストック。国内＝資金循環統計、国際＝IMF PIP（6月末・12月末は実績、それ以外の四半期は直近PIP＋国際収支フローの推計）。
* **③ 残高変化（DPOS）**：②の12か月差 ＝ 取引＋価格変動＋為替変動＋その他。国内も各時点の期末レートで換算した差なので、国際側と同じ性質。
* **期間の統一**：どの尺度でも、図の中のすべての矢印は同じ12か月（または同じ時点）。国内の単四半期と国際の12か月を混ぜない。
* **カード**：中央に純資金過不足（資金余剰／資金不足、②では純資産／純負債）、小さく資金運用／資金調達。この値は資金循環統計の部門合計（金融資産・負債の実測値）で、矢印の按分とは独立。
  検算：日本の金融部門 ≈ 均衡（+401億$）、米国の政府 資金不足 2.2兆$ ≈ 連邦＋州の赤字、ユーロ圏の家計 余剰 8,129億$。
* **米国フローの補正**：OECD経由の米国の四半期金融取引は年率換算（SAAR）で公表されているため4で割る（`oecd.py` の `SAAR_AREAS`）。他国は四半期値。
* **按分の重み**：フローは符号が混ざるため、相手部門の按分は「発行側の残高シェア」で行う（フローのシェアは使わない）。
* **実線／破線**：実線＝統計が相手先まで示す実績（ECB・日銀の whom-to-whom、PIP の二国間残高）、破線＝相手先を按分した推計・Nowcast推計。
* **集約ノード**：中国・金融センター・新興国は部門別統計が無いため、破線枠の「全主体・集約」セル。ホバーで IMF WEO の経常収支（世界への純資金供給）を参考表示。
* **線の絞り込み**：既定は合計の80%を占める主要フロー。上位10／25／50／すべて。セルをクリックでその主体の出入りだけ（青＝出し手、橙＝受け手）。
* **金融商品フィルタ**：すべて／債券／うち政府の債務（国債等：PIP の発行部門＝政府 ＋ 内訳なし分を政府の債券発行残高シェアで配分）／株式・投信／貸出／預金／保険・年金（後三者は二国間統計が無く国内のみ）。
* **読み解き**：①資金余剰の発生 → ②金融仲介 → ③国境を越える → ④資金不足のファイナンス、をデータから自動生成。加えて年ごとの背景解釈（金利・為替・政策）と IMF WEO の地域別指標。
* 次の候補：金融部門の細分化（銀行／保険／年金／投信／MMF、OECD S12x サブセクターの再取得が必要）、BIS 国際銀行統計による貸出の二国間、IMF DIP による直接投資の矢印（年次）。

## 第5版 ── ④ 評価変動と資産クラス別の富の増減

* **④ 評価変動（VAL）＝③ 残高変化 − ① 実取引**。同じ期間・同じキーでセル単位に差を取るので、矢印は「取引によらない保有価値の増減」（株価・債券価格・為替・その他変動）。
  保有者側はプラス＝評価益。発行者側は負債の時価変動なので、株式を発行する企業は株高で「評価損（純）」になる（株主の評価益の裏返し）、政府は金利上昇で国債の時価が下がると「評価益（純）」。ツールチップで説明。
* **資産クラス別パネル**（④で表示）：保有地域 × 資産クラス（株式・出資金／投資信託／債券／保険・年金／現金・預金・貸出／その他／不動産／金）の12か月評価変動と期首残高比。保有主体で絞り込み（全部門・家計・企業・政府・金融）。
  * 金融資産＝資金循環統計の残高差 − 取引（自国通貨ベースの価格効果を期末レートでUSD表示）。
  * 不動産＝家計の住宅・土地（OECD `DSD_NASEC10@DF_TABLE9B` 年次、N111N＋N211N）を BIS 住宅価格指数（`WS_SPP`, 名目）で四半期に延ばした価格効果の推計。米国のみ FRB Z.1 の再評価系列（FR155035005）を実績として使用。ユーロ圏＝独・仏・伊・西・蘭の合計。

## 第6版 ── 直近の価格指数と評価変動の Nowcast（ページ冒頭・常時表示）

* 新モジュール `pipeline/sources/prices.py`（`python build.py --only prices`、日次更新向き）：
  * OECD MEI `DSD_STES@DF_FINMARK`：株価指数（SHARE）・長期金利（IRLT）月次、20経済、約1か月ラグ（公的・月次の基準系列）。
  * 日次10年国債利回り：財務省（`jgbcme_all.csv`＋当月 `jgbcm.csv`）、米財務省（日次イールドカーブCSV）、英中銀（IUDMNZC）、ECB（AAA 10y）。
  * BIS `WS_XRU` 日次為替（全通貨「自国通貨/ドル」建て → 逆数で USD/自国通貨に統一）。
  * Yahoo Finance チャートAPI：主要株価指数（日経225・S&P500・ユーロストックス50・FTSE100・CSI300・ハンセン・STI・SMI・TSX・KOSPI・ASX200・SENSEX・ボベスパ・IPC・DAX）、金先物 GC=F、米債券ETF BND、米REIT ETF VNQ。参考値（非公式・配当除く）と明示。
* 配置：ヘッダー直下の独立セクション。尺度①〜④に関係なく常時表示し、基準時点は統計の最新四半期（資金循環統計の最終残高）に固定。保有主体の既定は「家計」。
* **直近指数の一覧**：地域ごとに株価指数の最新値・統計四半期末以降／年初来／12か月の変化、10年金利の水準と変化（bp）、通貨の対ドル変化、住宅価格の最新四半期、金（日次先物・IMF月次平均）、米国の債券・REIT ETF。
* **評価変動 Nowcast**：統計の最終時点（例 2026年Q1末）の保有残高 × その後の価格変化。株式＝株価指数（非上場株も同率と仮定）、債券＝−7×10年利回り変化、投信＝株60/債40、保険年金＝株40/債60、住宅＝BIS住宅価格に統計より新しい四半期があれば、金＝金価格（USD）を自国通貨換算。自国通貨の価格効果を直近為替でUSD表示し、為替の影響を最下行に分離。取引は含まない。
* 注記：「全部門」の合計は投信経由・年金経由の二重計上を含むため、最終的な富の持ち手は「家計」で見る。米国の公的金は簿価のため対象外。
