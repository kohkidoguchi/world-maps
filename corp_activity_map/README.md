# 世界企業活動マップ（corp_activity_map）

世界中の企業活動（買収・出資・設備投資・資金調達・提携・撤退・破綻・規制）を毎日集め、
**主体の大きさ × 動く資本量 × 将来影響** で重みづけして世界地図に置く。

```
Google News 検索RSS（英・日・独・中・仏・西・葡・韓・アラビア語、直近24時間）＋ FT Companies
        │  約1,000 本の見出し／日
        ▼  build.py  ── Claude (claude-opus-5, JSON Schema 構造化出力) が企業活動イベントを抽出
        │            主体・相手・活動種別・テーマ・活動地（緯度経度）・本社所在地・金額・主体規模・将来影響・出典
        ▼  data/events/YYYY-MM-DD.json（1日1ファイル）→ web/data.json（直近30日）
        ▼  web/     ── D3 世界地図（円＝重み、色＝活動種別、矢印＝国境を越える資本）＋ランキング＋国別／テーマ別集計
```

## 使い方

```bat
pip install -r requirements.txt
python build.py            # 見出し収集 → Claude 抽出 → data\events\ → web\data.json（初回実測：約1,100見出し → 114件、13分、入力6.4万＋出力6.3万トークン ≒ $2）
serve.bat                  # http://localhost:8767 で表示
run_daily.bat              # 日次実行用（タスクスケジューラに登録。コメント参照）
python build.py --fetch-only   # 見出しの収集だけ（費用ゼロ）
python build.py --reuse        # 保存済みの見出しで抽出だけやり直す
python build.py --json         # 保存済みイベントから web\data.json だけ再生成
```

`.env` は同フォルダに無ければ `../news_digest/.env` の `ANTHROPIC_API_KEY` を使う。
BCG プロキシ配下では `truststore` が必須（自動で有効化）。

## 重みの設計

| 軸 | 尺度 | 根拠 |
|---|---|---|
| 主体規模 S | 1〜5 | 年間売上（金融は運用資産）の桁：<10億ドル / 〜100億 / 〜500億 / 〜2,000億 / >2,000億ドル。Claude が知識で判定し `scale_note` に根拠 |
| 資本量 C | 1〜5 | 動く金額（ドル換算）の常用対数 −6（1億ドル=2、10億=3、100億=4、1,000億=5）。不明は 2 |
| 将来影響 F | 1〜5 | 不可逆性・波及範囲（地域／国／世界）・時間軸（短／中／長期）で Claude が評価し、1文の根拠を付す |

`total = 0.3S + 0.3C + 0.4F`。金額の大小に引きずられず、小さくても構造を変えるものが浮き上がるよう影響の比重を大きくしている。

**円の大きさ**（`web/app.js` の `drawMap`）：半径 ∝ ((total−1)/4)^2.6。面積比例だと重み5と重み3の差が3倍弱にしかならず「今日の重心」が見えないため、指数で上位を強調する（重み5は重み3の約6倍の半径、重み2は点）。
表示中の円の総面積が地図面積の12%になるよう全体を拡縮するので、フィルタで件数を絞ると残った円が大きくなる。重み4以上の上位6件は地図上に主体名を表示。
重なりは力学レイアウトで部分的に解消し、本来の位置からずれた円には引き出し線を引く。
係数は `build.py` の `weigh()` で変更できる（`--json` で再集計は不要、次回ビルドから反映。過去分は `weigh` を掛け直す小スクリプトで再計算可）。

## 画面

* **地図**：円の位置＝活動が起きる場所（工場の立地、買収対象の所在地など）。色＝資本取引（青）／実物投資（橙）／提携・契約・規制（緑）／縮小・撤退・破綻（赤の中抜き）。
  矢印＝主体の本社所在地 → 活動地（国が異なるもの＝国境を越える資本の動き）。
* **フィルタ**：活動種別チップ、テーマ、地域、重みの下限、企業名検索。「直近7日を重ねる」で1週間の蓄積を見る（古いものほど薄い）。
* **右パネル**：その日の「構造」（Claude が3〜5文で、資本がどこからどこへ何に向かっているかを描く）と重み順ランキング。3本のミニバー＝規模／資本／影響。
* **詳細**：円かランキングをクリック。要約、影響度の根拠、重みの内訳、出典リンク。
* **集計**：活動地の国別／本社所在国別／テーマ別（棒＝重みの合計、色＝種別内訳）。両者の差が「資本の輸出入」。

## 既知の制約と次の候補

* 見出しのみからの抽出なので、金額・規模・緯度経度は概算で誤りを含みうる。出典リンクで確認できるようにしている。
* Google News の検索 RSS は 1 クエリ最大 100 件・直近24時間。取りこぼしはクエリの追加で補う（`build.py` の `GN`）。
* 企業の売上・時価総額の機械的な照合（Wikidata／取引所データ）は未実装。Yahoo Finance の quoteSummary はプロキシ配下で crumb 認証に阻まれる。
* 次の候補：SEC 8-K（Item 1.01/2.01）や TDnet 適時開示の一次情報を見出しに混ぜる、週次・月次の「資本の流れマトリクス」（本社国 × 活動国）、テーマ別の時系列、メール配信との連動。
